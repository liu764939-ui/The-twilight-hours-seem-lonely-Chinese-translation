## 本次发布

**v9 · 第一章汉化版**（2026-11-13）

这一版把汉化推进到可以完整通读第一章的程度，并集中修掉了三个长期存在的问题：**正文缺字、断行错乱、BGM/音效丢失**。

### 更新内容

- **第一章全文本汉化**
  `scene1` ~ `scene8`（第一天：七不思议 → 黄昏 → 保健室 → 职员室）共 **756 条对话，0 条遗漏**，翻译词条 713 条。
- **修复正文缺字**
  原版对话窗口 `message_area(Wide)` 使用的字体是 `sharedassets0` 内的 `ロゴたいぷゴシック`，而非内置 Arial。此前只替换 Arial 时，正文实际仍由日文字体渲染，简体字（这 / 说 / 们 / 时 …）没有字形而显示为空白。本版**同时替换两套字体**，并保留各自的字号、行高、升降部度量。
- **修复断行错乱**
  引擎不做避头尾（禁则）处理，超宽时会在任意字符处硬折行。本版按消息框真实宽度（700px @ 24px 字号）与禁则规则**预断行**，断点以 `[r]` 写入脚本，并优先落在 `，。！？` 之后。
- **修复 BGM / 音效丢失**
  原版 OBB 中 `.resource`（音频 PCM 数据）为 **STORED 不压缩**；此前重打包时统一 deflate，导致音频资源无法按偏移读取。本版按原版方式打包并做 4 字节对齐。
- **图片汉化**
  - 封面竖排标题：右列「逢魔时」/ 左列「总是寂寞」
  - 标题按钮：「开始游戏」「继续游戏」（原 ハジメカラ / ツヅキカラ）
  - 旁白卡 `mono1`~`mono5` 五张（纯黑底白字，按原字号与行距整图重制）
  - 所有图片均按**原纹理格式与原 mip 层数**重编码，文件结构与原版一致
- **字体图集扩容**
  `libunity.so` 动态字体图集 1024 → 2048，避免汉字数量增多后图集重建导致的偶发缺字。

## 技术说明（供参考）

- 引擎：Unity 5.4（Mono），资源为独立 SerializedFile，通过 `globalgamemanagers` 的 ResourceManager 以 `(fileID, pathID)` 索引。
- 文本：`TextAsset` 为自定义 ADV 脚本格式，`[r]` 为显式换行、`[p]` 为翻页；渲染为逐字打字机效果。
- 回写：UnityPy 1.25.2 读写 bundle；图片按原始 `m_TextureFormat` 与 `m_MipCount` 生成整条 mip 链后替换 `m_ImageData`。
- 打包：`.resource` 保持 STORED 并 `zipalign -f 4`，其余条目 deflate；`useObb=False` 将全部数据内置于 APK assets。
- 字体：替换 `unity default resources` 的 Arial 与 `sharedassets0` 的 `ロゴたいぷゴシック`，度量字段保持不变；`libunity.so` 图集 1024→2048。
